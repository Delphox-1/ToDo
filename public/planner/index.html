홈 화면에 ToDo 설치

ToDo아이폰 · 아이패드
  1. 휴대폰 브라우저에서 ToDo 열기로그인 없이 이 브라우저에 저장합니다.
  2. 공유 버튼 → 홈 화면에 추가메뉴에 없으면 더 보기에서 찾을 수 있습니다.
  3. ‘웹 앱으로 열기’를 켜고 추가이 옵션이 보이는 경우 켜 주세요. 이름은 ToDo로 두면 됩니다.

홈 화면 기능은 브라우저에 따라 다릅니다. 휴대폰에서는 본인의 GitHub Pages 주소를 사용하세요. PC의 로컬 주소는 해당 PC에서만 열립니다. 기기 간 데이터는 백업 파일로 옮길 수 있습니다.

# ToDo1

**한국어** | [日本語](docs/README.ja.md) | [English](docs/README.en.md)

할 일, 주간 계획, 캘린더와 프로젝트를 관리하는 **내 컴퓨터용 개인 플래너**입니다. 코드를 내려받아 직접 실행하며, 일정은 현재 브라우저에 저장됩니다.

운영 사이트에 연결하지 않으며, 로그인·클라우드 계정·DB·비밀키 설정이 필요하지 않습니다. 외부 패키지를 설치하거나 빌드할 필요도 없습니다.

## 주요 기능

- 할 일 추가·수정·완료, 우선순위와 프로젝트 관리
- 주간 일정과 월간 캘린더
- 반복 일정과 할 일 검색
- JSON 파일 백업·복원
- 한국·일본 공휴일 표시

## 사용 방법

### 1. 준비

[Node.js](https://nodejs.org/) **22.13.0 이상**을 설치하세요. 설치 후 새 터미널을 열고 다음 명령이 버전을 출력하는지 확인합니다.

```sh
node --version
```

### 2. 코드 다운로드

이 저장소 상단의 **Code → Download ZIP**을 누른 뒤 압축을 풉니다. ZIP 내부에서 바로 실행하지 마세요.

Git을 사용한다면 다음 명령으로 받을 수도 있습니다.

```sh
git clone https://github.com/Delphox-1/ToDo1.git
cd ToDo1
```

### 3. 실행

**Windows:** 압축을 푼 폴더의 `Start-ToDo.cmd`를 더블클릭하세요. 열린 명령 창은 앱을 사용하는 동안 유지합니다.

**Windows·macOS·Linux 공통:** `package.json`이 있는 폴더에서 터미널을 열고 실행합니다.

```sh
node scripts/local-server.mjs
```

Node.js와 함께 설치된 npm을 사용하는 경우 `npm start`로 실행해도 됩니다. **`npm install`, `npm ci`, 빌드 작업은 필요하지 않습니다.**

### 4. 브라우저에서 사용

**http://127.0.0.1:4173**을 열고 할 일을 추가하세요. 로그인이나 회원가입은 없습니다.

터미널을 닫거나 **Ctrl+C**를 누르면 서버가 종료됩니다. 다시 실행한 뒤 **같은 브라우저와 같은 주소**로 접속하면 저장한 기록을 볼 수 있습니다. HTML 파일을 직접 더블클릭하는 대신 위 로컬 주소로 접속하세요.

## 데이터 저장과 백업

- 일정은 서버가 아니라 **현재 브라우저의 localStorage**에 저장됩니다. 개발자에게 전송되지 않습니다.
- 다른 브라우저·프로필·컴퓨터에는 자동으로 동기화되지 않습니다.
- **백업 내려받기**로 JSON 파일을 저장하고, 다른 환경에서는 **백업 가져오기**로 옮길 수 있습니다. 가져오기는 현재 데이터를 바꿀 수 있으므로 먼저 백업하세요.
- 브라우저 사이트 데이터 삭제, 시크릿 모드 종료, 저장 용량 초과로 기록이 사라지거나 저장이 실패할 수 있습니다. 정기적으로 백업하세요.
- 로컬 서버는 이 컴퓨터의 `127.0.0.1`에서만 열립니다. 다른 사람에게 이 로컬 주소를 보내도 그 사람이 내 앱에 접속할 수는 없습니다.
- 공휴일 정보는 인터넷이 연결돼 있으면 공개 공휴일 API에서 보완합니다. 연결이 없어도 할 일 관리는 가능하지만, 포함되지 않은 연도의 공휴일은 표시되지 않을 수 있습니다.

## 실행이 안 될 때

| 증상 | 해결 방법 |
| --- | --- |
| `node` 명령을 찾지 못함 | Node.js 설치 후 터미널을 새로 열거나 컴퓨터를 다시 시작하세요. |
| 파일을 찾을 수 없음 | ZIP 압축을 풀고 `package.json`과 `scripts` 폴더가 있는 위치에서 실행하세요. |
| 포트가 사용 중임 | 이전 ToDo1 실행 창을 닫고 다시 실행하세요. 필요하면 아래 명령으로 다른 포트를 선택합니다. |
| 이전 기록이 보이지 않음 | 이전에 쓰던 브라우저·프로필·주소·포트로 접속하세요. |
| 화면이 갱신되지 않음 | 서버가 실행 중인지 확인하고 브라우저를 새로고침하세요. |

```sh
node scripts/local-server.mjs --port 4174
```

다른 포트를 선택하면 **http://127.0.0.1:4174**로 접속합니다. 포트가 다르면 브라우저 저장 공간도 다르므로, 기존 기록은 원래 포트로 접속하거나 백업 파일을 가져와야 볼 수 있습니다.

## 개발 및 검증

서드파티 패키지 없이 Node.js 기본 기능으로 실행합니다. 테스트는 다음 명령으로 실행할 수 있습니다.

```sh
npm test
```

브라우저 코드는 `public/planner/`, 로컬 서버는 `scripts/local-server.mjs`에 있습니다. 일정 데이터는 저장소에 포함되지 않습니다.

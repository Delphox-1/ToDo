# ToDo1

[한국어](../README.md) | **日本語** | [English](README.en.md)

タスク、週間スケジュール、カレンダー、プロジェクトを管理する、**自分のパソコンで使う個人向けプランナー**です。コードをダウンロードして実行すると、予定は使用中のブラウザーに保存されます。

開発者の運用サイトには接続しません。ログイン、クラウドアカウント、DB、秘密鍵の設定は不要です。追加パッケージのインストールやビルドも必要ありません。

## 主な機能

- タスクの追加・編集・完了、優先度とプロジェクトの管理
- 週間スケジュールと月間カレンダー
- 繰り返しの予定とタスク検索
- JSONファイルによるバックアップと復元
- 韓国・日本の祝日表示

## 使い方

### 1. 準備

[Node.js](https://nodejs.org/) **22.13.0以上**をインストールします。新しいターミナルを開き、次のコマンドでバージョンが表示されることを確認してください。

```sh
node --version
```

### 2. コードをダウンロード

リポジトリ上部の **Code → Download ZIP** を選び、ZIPファイルを展開します。ZIPの中から直接実行しないでください。

Gitを使う場合は、次のコマンドでも取得できます。

```sh
git clone https://github.com/Delphox-1/ToDo1.git
cd ToDo1
```

### 3. 起動

**Windows:** 展開したフォルダー内の `Start-ToDo.cmd` をダブルクリックします。アプリの使用中は、開いたコマンドウィンドウを閉じないでください。

**Windows・macOS・Linux共通:** `package.json` があるフォルダーでターミナルを開き、次のコマンドを実行します。

```sh
node scripts/local-server.mjs
```

Node.jsに付属するnpmを使う場合は、`npm start` でも起動できます。**`npm install`、`npm ci`、ビルドは不要です。**

### 4. ブラウザーで使う

**http://127.0.0.1:4173** を開き、タスクを追加してください。ログインやユーザー登録はありません。

ターミナルを閉じるか **Ctrl+C** を押すとサーバーが停止します。再起動後に**同じブラウザーと同じURL**で開くと、保存した予定を確認できます。HTMLファイルを直接開くのではなく、上記のローカルURLにアクセスしてください。

## データ保存とバックアップ

- 予定はサーバーではなく、**使用中のブラウザーのlocalStorage**に保存されます。開発者には送信されません。
- 別のブラウザー、プロファイル、パソコンには自動で同期されません。
- バックアップのダウンロード機能でJSONファイルを保存し、別の環境でインポートするとデータを移せます。インポートによって現在のデータが変わる場合があるため、先にバックアップしてください。
- サイトデータの削除、プライベートブラウズの終了、保存容量の不足により、データが消えたり保存に失敗したりする場合があります。定期的にバックアップしてください。
- ローカルサーバーは、このパソコンの `127.0.0.1` でのみ待ち受けます。このローカルURLを他の人に送っても、その人があなたのアプリに接続できるわけではありません。
- インターネット接続がある場合、公開APIから祝日情報を補完します。オフラインでもタスク管理は使えますが、同梱データにない年の祝日は表示されない場合があります。

## 起動できないとき

| 症状 | 対処方法 |
| --- | --- |
| `node` が見つからない | Node.jsをインストールし、ターミナルを開き直すかパソコンを再起動してください。 |
| ファイルが見つからない | ZIPを展開し、`package.json` と `scripts` があるフォルダーで実行してください。 |
| ポートが使用中 | 以前起動したToDo1のウィンドウを閉じて再実行してください。必要なら下記のコマンドでポートを変更できます。 |
| 以前の予定が表示されない | 以前と同じブラウザー、プロファイル、URL、ポートを使用してください。 |
| 画面が更新されない | サーバーが起動していることを確認し、ページを再読み込みしてください。 |

```sh
node scripts/local-server.mjs --port 4174
```

この場合は **http://127.0.0.1:4174** を開きます。ポートが変わるとブラウザーの保存領域も変わります。以前のデータを見るには元のポートを使うか、バックアップをインポートしてください。

## 開発と検証

追加パッケージを使わず、Node.jsの標準機能で動作します。テストは次のコマンドで実行できます。

```sh
npm test
```

ブラウザー側のコードは `public/planner/`、ローカルサーバーは `scripts/local-server.mjs` にあります。個人の予定データはリポジトリに含まれていません。
